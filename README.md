# Simple Interest Calculator

A simple command-line calculator that computes simple interest given the principal amount, annual rate of interest, and time period in years.

## Project Details
- **Project Name:** Simple Interest Calculator
- **Description:** A Bash script application that calculates simple interest based on user inputs.

## Formula
Simple interest is calculated using the following formula:
$$\text{Simple Interest} = \frac{P \times T \times R}{100}$$

## Input Fields
- `p`: Principal amount
- `r`: Annual rate of interest
- `t`: Time period in years

## Output
- `simple interest = (p * t * r) / 100`

## Usage
Run the Bash script in your terminal:
```bash
chmod +x simple-interest.sh
./simple-interest.sh
```

Follow the prompts to enter the principal, rate of interest, and time period.
