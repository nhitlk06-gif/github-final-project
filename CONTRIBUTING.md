# Contributing to Simple Interest Calculator

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

## Ways to Contribute
You can contribute to this project by:
- Reporting bugs and issues.
- Suggesting new enhancements or features.
- Writing or improving documentation.
- Submitting bug fixes and pull requests.

## Contribution Guidelines
1. **Fork the repository** to your own GitHub account.
2. **Clone your fork** locally to your development environment.
3. **Create a new branch** for your feature or bug fix:
   ```bash
   git checkout -b feature/your-feature-name
   ```
4. **Make changes** and ensure everything works as expected.
5. **Commit your changes** with descriptive commit messages:
   ```bash
   git commit -m "Add descriptive commit message"
   ```
6. **Push to your fork**:
   ```bash
   git push origin feature/your-feature-name
   ```
7. **Submit a Pull Request** against the `main` branch with a clear description of the modifications.

Thank you for contributing!
